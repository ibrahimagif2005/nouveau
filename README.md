# Projet Ecommerce

Ce projet est une application de commerce électronique de base.

## Structure du Projet

Le projet est organisé comme suit :

- `/frontend`: Contient le code de l'interface utilisateur (par exemple, HTML, CSS, JavaScript, ou un framework comme React/Vue/Angular).
- `/backend`: Contient la logique serveur de l'application (par exemple, API, gestion des requêtes, interaction avec la base de données).
- `/database`: Contient les scripts de migration, le schéma de la base de données, et potentiellement des seeds.
